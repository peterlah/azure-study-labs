## 검증 항목

- [ ] README와 실행 파일을 모두 확인했습니다.
- [ ] 실제 키, 토큰, 구독 ID와 개인 환경값이 없습니다.
- [ ] 설치 및 버전 확인 명령이 현재 환경에서 동작합니다.
- [ ] 정적 검사와 변경 전 확인 명령이 성공합니다.
- [ ] 실제 배포가 성공합니다.
- [ ] 예상 결과를 명령 출력과 Azure 리소스에서 확인했습니다.
- [ ] 정리 명령이 성공하고 잔여 리소스가 없습니다.
- [ ] 사이트에서 사용할 README와 코드가 최신입니다.

## 실행 결과
